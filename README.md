# Ghost in the Machine

![A logo spelling out Ghost in the Machine](banner.png)

You've met with a terrible fate, haven't you?

Submission for the 14-day [Time Loop Mod Jam](https://outerwildsmods.com/jam/aug-2026/)!

This mod assumes you've completed the base game on your current save profile. Users playing on a fresh profile may find exploration more difficult than intended.

> [!WARNING]
> Ghost in the Machine is intended to be played standalone. Please disable other story mods before playing it, if any are enabled.

> [!WARNING]
> Mods that allow you to skip the death and flashback sequences like [General Enhancements](https://outerwildsmods.com/mods/generalenhancements/) or [Time Saver](https://outerwildsmods.com/mods/timesaver/) will break the mod if used to do so. Use at your own risk.


Supports [Achievements+](https://outerwildsmods.com/mods/achievements/)! Install it alongside this mod to unlock achievements for finding easter eggs and completing optional challenges. To avoid spoilers, don't open the full achievements list until you've completed the mod.

Ernesto is around here somewhere, but you'll have to make a truly terrible decision to meet him.
